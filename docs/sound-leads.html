Make the same J-cut

  1. Keep 0.250–1.750 s from Green Means Go and 1.000–2.500 s from Night Run. Use the source files linked on those pages.
  2. Keep the picture cut at 1.500 s. In pass B, extend the incoming audio edge to include its source from 0.700 s. Keep the original sound in sync once the second shot is on screen.
  3. Blend the two audio tracks over the 300 ms overlap. Compare at the same playback volume. Extend or shorten the overlap if it steps on dialogue.

Rebuild the two audio passes

Save the Green Means Go source, the Night Run source and the replay script in the same directory. With Python 3 and FFmpeg on your path, run the command below.

python replay.py green-means-go-original.mp4 night-run-original.mp4 j-cut-output

The script writes two 3-second WAVs and checks that their samples match outside the 300 ms overlap. These are the audio passes before final mastering. Put either WAV under the same picture cut at 1.500 s.
