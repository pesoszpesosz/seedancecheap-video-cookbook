01 / START WITH YOUR IMAGES

Add the images you own

Open Studio 2 → Brand Canvas and add your images. Our test used an earlier Studio 2 Nano Banana PRO courier image and a still from our Seedance 2.5 drama model test.

Those source images already existed; the free branding step did not generate them.

02 / BUILD THE TEXT LAYOUT

Give every page a signature

Add a headline, a short feature line and your website. Use the same layers across the pages, then inspect each image before exporting.

A different face, subject or crop can need a different placement. Keep important details clear.

03 / CHECK AND EXPORT

Export the whole set

Use Export all as ZIP. Our native export contained two original-size PNGs. Open each file and check the text, edges and image quality.

Save your project if you want to return to the layout. We verified that our saved project reopened with both pages and all three layers.

The layout we used

  • Headline: “Your image. Your signature.” in bold Arial, mint #d7ff72, sized at 9% of image width.
  • Feature: “Brand Canvas · Free export” in white Arial, 4% width, with an outline.
  • Footer: “seedancecheap.com” in bold white Arial, 4% width, with an outline.

The headline sits near the top, the feature line below it and the website near the bottom. The actual exports above show the result on both images.
