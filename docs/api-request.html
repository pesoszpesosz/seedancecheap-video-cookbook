Replace vid_YOUR_ID with the ID returned by create or recovery. Space status checks, for example 30 seconds apart, and keep your application’s waiting screen tied to this job.

      
4. Download after Ready

      

      
Download within 48 hours after delivery, before the exact expiry time shown in your studio or job receipt. Check the curl exit code before opening the file. Play the full result and inspect source dimensions, motion and sound separately.

      
The JSON commands require curl 7.76 or newer for --fail-with-body. HTTP errors return a nonzero exit code; their saved JSON is an error receipt, not a successful job. Windows examples use curl.exe.

What you seeNext step

        
Active or uncertainKeep the same job and inspect its status. A slow request is not finished footage.
