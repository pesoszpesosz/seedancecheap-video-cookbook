# The Catch

[Watch the complete eight-second short and jump to three key frames](https://pesoszpesosz.github.io/seedancecheap-video-cookbook/the-catch.html?from=github). The SeedanceCheap team made the original animation and synthesized sound with Codex.

Open the self-contained HTML file in a browser. In the browser console, use `window.__seek(3.23)` to inspect the pre-impact gap and `window.__seek(3.53)` to inspect the stopped cage. The export samples the same function at `frameIndex / 30` for 240 frames.

Run `python sound.py` in this directory to generate the original 48 kHz stereo WAV. The timed events share the animation’s 0.52-second cable break and 3.46-second contact.
